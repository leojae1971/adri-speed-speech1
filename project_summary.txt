2.  DESCRIPCIÓN DE ARCHIVOS CLAVE (UBICACIÓN Y FUNCIÓN)
--------------------------------------------------

📱 FRONTEND (Flutter)
─────────────────────
lib/main.dart
   → Punto de entrada de la app. Configura MultiProvider, rutas y tema.

lib/core/services/ai_service.dart
   → Gestiona la comunicación con el backend (LLM). Envía mensajes y recibe respuestas con audio.

lib/core/services/hybrid_tts_service.dart
   → Controla el Text-to-Speech (Edge TTS, Azure, Google). Reproduce la voz del avatar y la traducción.

lib/core/services/speech_service.dart
   → Reconocimiento de voz (Speech-to-Text). Maneja permisos, dictado y locales.

lib/core/services/avatar/adri_avatar_widget.dart
   → Widget del avatar. Muestra expresiones faciales y movimiento de labios (visemes) sincronizados con el audio.

lib/core/services/avatar/dialogue_script_parser.dart
   → Parsea el texto etiquetado con [EXPRESIÓN] que devuelve el LLM y lo convierte en animaciones del avatar.

lib/features/vocabulary/presentation/screens/chat_screen.dart
   → Pantalla principal de chat. Contiene el selector de idiomas, el historial, el micrófono, el envío de mensajes y la reproducción de audio.

lib/features/vocabulary/presentation/screens/image_translation_screen.dart
   → Pantalla de traducción con cámara (OCR). Escanea texto y debería traducirlo (actualmente solo muestra el texto escaneado, sin traducción).

lib/core/config/api_config.dart
   → Configuración de la URL del backend y tiempo de espera de las peticiones.

lib/core/config/ai_persona_config.dart
   → Prompts del sistema para el LLM, con personalización según el idioma y el nivel del usuario.

lib/core/utils/language_detector.dart
   → Detecta el idioma del texto del usuario (para cambiar automáticamente el avatar).

lib/l10n/
   → Archivos de internacionalización (traducciones de la interfaz de usuario).

assets/avatars/
   → Imágenes de los avatares (41 archivos .png, uno por idioma).


⚙️  BACKEND (Python / FastAPI)
─────────────────────────────
adri_speed_speech_backend/main.py
   → Punto de entrada del backend. Define los endpoints /chat, /tts, /transcribe y /health.

adri_speed_speech_backend/router.py
   → Orquesta la cadena de proveedores (LLM, TTS, STT). Maneja cuotas, circuit breaker y caché.

adri_speed_speech_backend/providers/llm_providers.py
   → Implementación de los proveedores LLM: Groq, Cerebras, Gemini Flash, DeepSeek.

adri_speed_speech_backend/providers/tts_providers.py
   → Implementación de proveedores TTS: Edge TTS (principal), Azure, Google WaveNet.

adri_speed_speech_backend/providers/stt_providers.py
   → Implementación de proveedores STT: Groq Whisper (backup).

adri_speed_speech_backend/cache.py
   → Caché de audio TTS con expiración (TTL de 30 días).

adri_speed_speech_backend/quota_manager.py
   → Gestiona las cuotas diarias y mensuales de cada proveedor.

adri_speed_speech_backend/circuit_breaker.py
   → Implementa un circuit breaker para evitar saturar proveedores que fallan.

adri_speed_speech_backend/model_catalog.py
   → Sincroniza el catálogo de modelos de los proveedores para detectar cambios.

adri_speed_speech_backend/startup_checks.py
   → Validaciones al arrancar el backend (versión de modelos, conectividad).

adri_speed_speech_backend/requirements.txt
   → Dependencias de Python del backend.


📦 OTROS ARCHIVOS IMPORTANTES
─────────────────────────────
pubspec.yaml
   → Dependencias de Flutter y assets declarados.

android/app/src/main/AndroidManifest.xml
   → Permisos de Android, incluyendo micrófono, cámara y el bloque <queries> para reconocimiento de voz.

ios/Runner/Info.plist
   → Configuración de iOS (permisos, localizaciones).
